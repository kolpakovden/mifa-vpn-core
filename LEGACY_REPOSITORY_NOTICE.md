# ⚠️ Project archived — development completed

This repository represents the original **MIFA VPN Platform** architecture.

The platform proved stable and reliable in production. Further development of this architecture has been stopped intentionally: Grafana, Prometheus, Loki, Promtail and related monitoring components created more operational complexity and digital noise than the current deployment required.

Active development has moved to **MIFA VPN Core**, a simplified architecture focused on the components used in production: Xray, nginx/TLS, Telegram management and backup/restore.

This repository is retained as a historical stable release and reference implementation.
